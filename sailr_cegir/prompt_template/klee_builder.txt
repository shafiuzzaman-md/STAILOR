STRICT CODING RULES
====================

A) ENTRYPOINT USAGE
- You MUST call the required entrypoint specified by the Frozen Plan.
- You MUST NOT define the entrypoint body.
- If you create a wrapper, it must be uniquely named (prefix stub_) and must call the
  real entrypoint exactly once. main() may call either the entrypoint directly OR the wrapper.

B) COMPLEX TYPES & MEMORY (CRITICAL)
- DO NOT use `malloc()` + `klee_make_symbolic` to fake complex library structures (e.g., context objects, state handles).
- CAUSE: This creates invalid internal state/pointers (ABI mismatch) and causes early crashes.
- ACTION: Use the library's real constructor functions whenever possible.
- If you must allocate manually, you MUST include the real header definitions. DO NOT define "minimal structs" that might mismatch the binary layout.

C) STUB POLICY (ONLY EXTERNAL DEPENDENCIES)
- Allowed stubs: ONLY for external dependencies that are not part of the target.
- [REPLAY REQUIREMENT] If you stub 'malloc'/'calloc', you MUST implement the 'strict_alloc' pattern 
  for the Replay build. This ensures Heap OOB Reads trigger a crash even if they hit padding.

    /* Copy this helper into your Stub Functions section */
    #ifndef __KLEE__
    #include <sys/mman.h>
    #include <unistd.h>
    void* strict_alloc(size_t size) {
        size_t page_size = sysconf(_SC_PAGESIZE);
        size_t num_pages = (size + page_size - 1) / page_size + 1;
        size_t total_size = num_pages * page_size;
        char* base = mmap(NULL, total_size, PROT_READ|PROT_WRITE, MAP_PRIVATE|MAP_ANONYMOUS, -1, 0);
        if (base == MAP_FAILED) return NULL;
        char* guard = base + (num_pages - 1) * page_size;
        mprotect(guard, page_size, PROT_NONE);
        return guard - size;
    }
    #endif

D) EMBEDDED FUNCTIONS

  is needed by the harness (e.g., tiny utilities like stub_strlen, stub_memcpy).
- Do NOT paste/copy target source code here.

E) SYMBOLIC INPUTS
- Use klee_make_symbolic on raw byte buffers and primitive scalars.
- For pointer parameters: allocate fixed-size buffers (concrete allocation) and make their contents symbolic.
- Use klee_assume only for reachability constraints that do NOT negate the bug predicate.
- LENGTH CONSTRAINTS: Always constrain symbolic lengths to be small to speed up execution.
     > Example: klee_assume(len < 16);
     > Why: This prevents KLEE from unrolling loops (strlen/hashing) for thousands of iterations.

F) NO PROXY ASSERTIONS (ANTI-HALLUCINATION)
- You CANNOT access local variables inside the target library.
- HYBRID STRATEGY for Invisible Bugs (Memory Corruption):
  - If the bug is an OOB/UAF dependent on hidden internals, DO NOT create fake variables.
  - WRITE: BUG_ASSERT(0);
  - This tells the system: "If I reach this line alive, the bug didn't happen."
  - The system will catch the crash (SegFault) automatically.
- For Logic Bugs (Return Values), YOU MUST ASSERT THE STATE explicitly.

G) STRING SAFETY (CRITICAL):
   - If you create a symbolic 'char' buffer that is passed to a string function (uses strlen),
     you MUST manually null-terminate it to prevent OOB reads.
   - CORRECT:
     char buf[100];
     klee_make_symbolic(buf, sizeof(buf), "buf");
     buf[sizeof(buf) - 1] = '\0'; // <--- MANDATORY SAFETY
   - Why: klee_make_symbolic() does NOT guarantee a null byte. Without this, strlen() reads forever and crashes.

ASSERTION MACROS (DO NOT CHANGE NAMES)
====================
- BUG_ASSERT(<predicate>) asserts the bug condition.
  Definition: #define BUG_ASSERT(cond) klee_assert(!(cond) && "BUG_ASSERT")
  Meaning: "Assert that 'cond' is FALSE. If 'cond' becomes TRUE, crash."
  Usage:
    - Logic Bug: BUG_ASSERT(x < 0); // Crashes if x < 0
    - Crash Oracle: BUG_ASSERT(0);  // Never crashes (Safe Landing)

- REACH_ASSERT() is a sentinel used to score reachability.
