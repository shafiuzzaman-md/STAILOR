NON-NEGOTIABLE OUTPUT CONTRACT (READ FIRST)
1) Output MUST be valid JSON ONLY:
   {"harness":"<C code>"}
   - No markdown fences. No prose outside JSON. No extra keys.

2) The C code MUST contain these section markers in this exact order:
   /* --- Global Constants --- */
   /* --- Stub Functions --- */
   /* --- Embedded Functions --- */
   /* --- Harness --- */

3) The Harness section MUST define:
   int main(int argc, char **argv)
   - main() MUST be the FIRST function in the Harness section.

4) DO NOT provide function bodies for any real target/library symbols.
   - If a function exists in the target, you MUST NOT define it.
   - You may only: #include headers OR declare extern prototypes (NO body).

5) Execution order inside main() MUST be:
   (A) prepare inputs
   (B) call the real entrypoint
   (C) BUG_ASSERT(<bug predicate>)
   (D) REACH_ASSERT()

PIPELINE AWARENESS (IMPORTANT)
- Phase II runs under KLEE to find inputs that trigger the bug predicate.
- Phase III replays the harness against the REAL target implementation.
- Therefore: DO NOT rely on semantic/reachability stubs (e.g., overriding target hashing,
  parsing, dispatch, or internal logic). Those will not be honored in strict replay.

====================
STRICT CODING RULES
====================

A) ENTRYPOINT USAGE
- You MUST call the required entrypoint specified by the Frozen Plan.
- You MUST NOT define the entrypoint body.
- If you create a wrapper, it must be uniquely named (prefix stub_) and must call the
  real entrypoint exactly once. main() may call either the entrypoint directly OR the wrapper.

B) STUB POLICY (ONLY EXTERNAL DEPENDENCIES)
- Allowed stubs: ONLY for external dependencies that are not part of the target and are required
  to compile/run (e.g., OS glue, filesystem, environment, time, allocator wrappers, printing).
- Forbidden stubs:
  1) Any override of a target/library function or its semantics.
  2) Any stub that forces reachability or forces the bug (semantic shortcuts).
  3) Any “fake implementation” of core logic.

- All stubs must live in /* --- Stub Functions --- */ and MUST be minimal and semantics-neutral:
  return a safe default OR forward to standard C equivalents if available.

C) EMBEDDED FUNCTIONS
- Use /* --- Embedded Functions --- */ ONLY for helper code that is not provided by the target and
  is needed by the harness (e.g., tiny utilities like stub_strlen, stub_memcpy).
- Do NOT paste/copy target source code here.

D) SYMBOLIC INPUTS
- Use klee_make_symbolic on raw byte buffers and primitive scalars.
- For pointer parameters: allocate fixed-size buffers (concrete allocation) and make their contents symbolic.
- Use klee_assume only for reachability constraints that do NOT negate the bug predicate.

E) NO PROXY ASSERTIONS (ANTI-HALLUCINATION)
- You CANNOT access local variables inside the target library.
- DO NOT create a new symbolic variable just to assert on it (e.g., 'int bug_hit; klee_make_symbolic(&bug_hit...); BUG_ASSERT(bug_hit)').
- This is a "Self-Fulfilling Prophecy" and is strictly FORBIDDEN.
- If the Frozen Plan predicate targets an invisible local variable, you must assert on the *observable consequence* (e.g. crash, return value) or a side-effect, NOT the variable itself.

====================
MANDATORY MAIN SKELETON (FOLLOW THIS SHAPE)
====================

Inside /* --- Harness --- */ you MUST produce:

int main(int argc, char **argv) {
  // 1) declare variables matching the entrypoint signature
  // 2) allocate concrete buffers for pointer args (fixed size)
  // 3) klee_make_symbolic(...) for symbolic inputs
  // 4) optional klee_assume(...) for reachability only (must not negate bug predicate)
  // 5) call the real entrypoint (extern prototype or header)
  // 6) BUG_ASSERT(<bug predicate from Frozen Plan>)
  // 7) REACH_ASSERT()
  return 0;
}

====================
ASSERTION MACROS (DO NOT CHANGE NAMES)
====================
- BUG_ASSERT(<predicate>) asserts the bug condition.
- REACH_ASSERT() is a sentinel used to score reachability.

If these macros are already defined in the harness template provided by the system,
DO NOT redefine them.

OUTPUT FORMAT (FINAL)

Return JSON only:
{"harness":"<full C code with all four sections and a main()>"}
